Full phase-by-phase contents

The legacy ordered list, grouped by dev phase. Useful if you already know which phase you're re-testing. Most clients should start with the role buttons above instead.

  1. Client demo script — 35-minute narrative walk-through of every feature (for live demos)
  2. Test accounts & ground rules — meet Tia, Aguirre, Goode, and Aguirre before you start
  3. 📖 Glossary — commingled, Yellow Sheet, contamination severity, zone, depot, and every other term the guides use
  4. Accounts & sign-in — create every role (admin / resident / employees) and verify sign-in works. Replaces the old "Generating users" and "Phase 1" guides.
  5. Phases 0 & 2 are internal setup (foundation, shared code) — nothing to click through.
  6. Phase 3 · Resident app — dashboard, order bags, scan, calculator, rewards
  7. Phase 4 · Admin dashboard — invites, zones, pricing, gift card queue
  8. Phase 5 · Route builder — plan tomorrow's pickups and assign a driver
  9. Phase 6 · Operator day — start the route, scan bags, deliver stickers, close out
  10. Phase 7 · Depot day — receive routes, weigh bags, award points, read inventory
  11. Phase 8 is the depot manager flow — covered in-app on the Manager pages.
  12. Phase 9 · Admin polish — zone performance, contamination strikes, operator leaderboard, compliance notices
  13. Phase 10 · QR sticker generation — pre-print sticker sheets so delivery can claim them
  14. Phase 11 · Post-deploy smoke test — 5-minute role-by-role check after the dev team ships to production
  15. Phase 12 · Pilot launch checklist — hardware, doorstep pitch, week-one operations, retro
