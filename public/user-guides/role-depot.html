Depot Testing as a depot worker

The sorting-floor role. Receive completed routes, scan bags into the process form, weigh the 7 materials, flag contamination, submit. Each submission awards points to the resident and adds to inventory — all in one atomic write.

Device: 💻 Laptop or tablet — the form has 7 weight fields, so a real keyboard is easier than thumbs-on-glass.
Who you'll be: Depot Goode (depot.goode@wbct-pilot.test).

⚠️ What's stubbed in this flow
  • Weighing is manual — weights are typed in by hand. No Bluetooth / USB scale integration in the pilot.
  • SMS to residents (points awarded) is logged to the server console, not sent as a real text.

Prerequisites

Depot testing needs earlier roles to have done their part — the Incoming list is empty without them.

  • Phase 4 — admin has set Yellow Sheet prices for all 7 materials and created a depot linked to Goode.
  • Phase 5 — a route has been built for an operator.
  • Phase 6 · Scenario 6 — the operator has completed the route and tapped Deliver to depot.

See the incoming route

Sign in as Goode. The depot home redirects to /depot/incoming. You should see the operator's completed route as a NEW card.

Scan a bag into the process form

Tap the route, then scan a bag QR (or type the printed code). The form opens with the resident's name and bag number.

→ Depot day · Scenario 3

3

Process a clean bag

Type weights in the material rows. Leave contamination on None. Watch the live points preview, then submit. Cross-check that the resident's points balance actually went up by the expected amount.

Apr 27 additions: the form now only renders rows for materials this depot accepts (configured by admin). If admin has a Pricing campaign live, a 🔥 Active campaign banner appears above contamination and the points preview reflects the multiplier — see Phase 7 · Scenario 4b.
