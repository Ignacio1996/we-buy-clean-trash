Glossary

Every term the guides use that isn't obvious from context. If you hit a word you don't know, check here first — chances are it has a very specific meaning in the pilot.

Jump to: App terms Recycling terms Roles Tech terms

App terms

Bag
A single recycling bag with a unique QR sticker. The QR carries the bag's ID (printed as BAG-4237-03, read as sheet 4237, bag 3 of 10). A bag is what a resident fills and a depot worker weighs.
Bag order
A resident's request for more physical bags, placed from the Order more bags screen. One order buys one or more sticker-sheet equivalents (10 bags each) and gets enqueued onto the next open route for the resident's zone so an operator delivers them.
Bag processing
The act of a depot worker weighing the 7 materials inside a bag, setting a contamination level, and submitting. One submission = one bagProcessing record and one points-ledger entry for the resident.
Sticker sheet
A printed page (2.25″×1.25″ labels on Rollo thermal stock) of 10 QR stickers that all share a 4-digit sheet number. Generated by admin before operators can deliver bags. Creating the sheet atomically creates one stickerSheets doc + 10 bag records.
Route
An ordered list of stops an operator drives in one day. Contains pickups (scanned bags from residents) and deliveries (sticker sheets for bag orders). Tia builds routes the day before; the Google Maps Routes API optimizes stop order.
Pickup
A completed visit where an operator scanned a resident's filled bag, optionally took a doorstep photo, and marked the stop done. A pickup is different from "delivery" (dropping off new stickers) — one route can have both.
Yellow Sheet
The table of per-material market prices (dollars per pound) that admins maintain in /admin/pricing. Named after the industry term — a real recycling depot's weekly price list is traditionally printed on yellow paper. Changing a yellow-sheet value immediately affects how many points residents earn from new bags.
Zone
A geographic service area (one or more zip codes). Every resident is tied to one zone; every depot serves one or more zones. The pilot uses a single zone ("Kirk pilot") covering 80301.
Depot
A physical sorting facility where delivered routes are processed. Each depot has its own inventory (7 materials). Depot workers are linked to a specific depot at invite time so their processed bags update the right inventory.
Signup bonus
A one-time 10,000-point credit every new resident gets on signup. Appears as a signup_bonus transaction in the ledger. 100,000 pts = $10, so the bonus is worth roughly $1.

Recycling terms

Commingled
"All mixed together." The default bag type — the resident puts all their recyclables in one bag without sorting. Gets the standard points multiplier (1×).
Separated
The opposite of commingled — the resident declares that their bag contains only one kind of material, or that they've pre-sorted it. Earns a 2× points multiplier because pre-sorted material is worth more to a depot.
Contamination
Non-recyclable junk in a recyclable bag (food waste, plastic film in a paper bag, etc.). The depot worker sets a severity level when processing; the severity reduces the points awarded.
Contamination severity
One of four levels set at process time:
  • None — clean bag. No penalty.
  • Minor — 30% penalty.
  • Major — 60% penalty.
  • Severe — 90% penalty (resident still gets credit, just very little).
The 7 materials
Every bag is weighed across these seven categories, each with its own market price: aluminum, tin/steel, cardboard, paper, PET (clear bottles), HDPE (milk-jug-style), and mixed plastic (everything else).
Mill shipment
When a depot sends processed material to a recycling mill. Subtracts from the depot's inventory. The depot manager records these in the /manager pages.

Roles

Resident
A homeowner with an address in a pilot zone. Self-signs up. Orders bags, scans them before pickup, earns points, redeems them. Played by Casey / Devon / Eden / Frankie / Greer in the guides.
Operator
The driver. Runs routes on a phone, scans bags at each stop, delivers new sticker sheets, closes out at the depot. Invite-only (no self-signup). Played by Aguirre in the guides.
Depot worker
Works at a sorting depot. Weighs bags, flags contamination, submits points. Invite-only, and the admin must pick which depot they're linked to at invite time. Played by Goode.
Depot manager
Runs a depot. Sees inventory, records mill shipments, oversees depot workers. Invite-only and depot-linked. Covered in Phase 8 (not yet built).
Admin
The back-office role. Sends invites, edits pricing, creates zones/depots, builds routes, fulfills gift-card redemptions manually, prints compliance notices. Invite-only. Played by Tia.

Tech terms (rarely need these)

Custom claims
A Firebase Auth feature that tags a user account with extra info (e.g. role: admin). The app reads these claims to decide which pages you're allowed to see. Invisible to testers — they just determine where you land after sign-in.
Firestore
Google's cloud database. All app data lives there. Mentioned occasionally in expected blocks ("a new bagProcessing doc appears in Firestore") — mostly a concern for developers.
Ledger / transactions
The immutable record of every points change. Signup bonus, pickup awards, redemptions — each writes a new row. A resident's current balance is always the running sum of their ledger entries.
Stub
A fake version of an external service used during the pilot (e.g. the SMS stub logs messages to the server console instead of actually texting). See each guide's ⚠️ What's stubbed box.
Idempotent
Running the same operation twice produces the same end state as running it once. The pilot seed script (npm run seed:pilot) is idempotent — re-running it doesn't duplicate test users.
